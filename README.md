**Conto A Capo** è un'applicazione web sviluppata per semplificare e automatizzare il calcolo e la suddivisione delle spese condivise all'interno di gruppi di persone (viaggi, cene, convivenze, eventi).

🔗 **Demo Live:** [conto-acapo.web.app](https://conto-acapo.web.app)

---

## 💡 Il Problema Risolto

Spesso gestire le spese in gruppo porta a confusione su chi deve quanto a chi. **Conto A Capo** calcola in tempo reale i saldi di ogni partecipante e restituisce il piano di rimborsi minimo ed efficiente tra i membri del gruppo.

---

## 🚀 Stack Tecnologico

* **Front-End:** Angular (Componenti Standalone, Reactive Forms, Signals)
* **Linguaggio:** TypeScript (ES6+)
* **Styling:** Tailwind CSS (Interfaccia reattiva e ottimizzata per smartphone)
* **Cloud & Hosting:** Firebase Hosting & Cloud Firestore

---

## ✨ Funzionalità

* Inserimento rapido di partecipanti e spese sostenute.
* Algoritmo di ripartizione automatica dei debiti/crediti.
* Interfaccia pulita, accessibile e responsive.
* Persistenza dati e sincronizzazione su Firebase.

---

## 🛠️ Esecuzione in Locale

1. Clona il repository:
   ```bash
   git clone https://github.com/Jayson1902/conto-acapo.git
   cd conto-acapo
   ```

2. Installa i pacchetti:
   ```bash
   npm install
   ```

3. Avvia l'applicazione:
   ```bash
   npm start
   ```
   Apri `http://localhost:4200/` nel browser.
